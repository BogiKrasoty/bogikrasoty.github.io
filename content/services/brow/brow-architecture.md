### Для кого
Всем, кто хочет «свою» идеальную форму бровей — не по шаблону, а по пропорциям лица, анатомии брови и привычке клиента. Идеально перед первым окрашиванием/ламинированием.

### Программа
- Анализ лица: овал, симметрия, посадочное место бровей, природа роста волоса
- Каркасное построение: 3 точки (начало, пик, хвост) по правилу «золотого сечения» / индивидуальной схеме
- Коррекция форме: пинцет / воск / нить — удаление только лишнего, сохранение натуральной густыни
- Финальная укладка: гель/воск для фиксации направления роста
- Рекомендации по уходу и выращиванию (если нужно)

### Результат
Симметричная, гармоничная форма бровей, которая «поднимает» взгляд, открывает век, балансирует лицо. Основа для любого следующего этапа — окрашивания, ламинирования, перманента.

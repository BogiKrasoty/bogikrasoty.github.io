### Для кого
Владельцам своих ресниц, которые хотят эффект «уже накрашенных» без наращивания. Даёт изгиб, длину визуально, густоту, питание. Идеально для прямых, спущенных вниз ресниц. Держится 5–7 недель.

### Программа
- Очистка, обезжиривание
- Подбор ролика под нужный изгиб (C/D/L — натуральный / драматичный / лисьий)
- Нанесение 1-го состава (размягчение) — время под тип волоса
- Укладка ресниц на ролик, фиксация направления
- Нанесение 2-го состава (фиксация новой формы)
- Коллагенирование / кератинирование — питание, восстановление, блеск
- Опционально: окрашивание красителем для насыщенности
- Снятие ролика, финальная укладка

### Результат
Ресницы уложены вверх, выглядят длиннее на 30–50%, гуще, блестящие. Эффект туши без туши — утром только расчесать. Питание изнутри — ресницы не ломаются, растут лучше. Без ущерба для своих — можно делать регулярно.

### Для кого
Невеста, подружки, мамы, выпускницы, гости событий — нужна укладка, которая держит весь день/ночь, не рассыпается, выглядит дорого. Любая длина волос (от каре до талии), любой тип (прямые/волнистые/кудрявые/порощистые).

### Программа
- Консультация (за 1–2 недели до события / день пробника): референсы, наряд, аксессуары, Schleier, фото в движении
- Пробник (опционально, входит в свадебный пакет / отдельно): полная укладка + фиксация, проверка устойчивости, фото/видео
- День события: подготовка волос (мойка / сухая укладка / термозащита)
- База: волюмизатор / текстурный спрей / мусс / пудра для объёма у корней
- Укладка: бигуди / плойка / утюжок / плетенка / волны / хвост / пучок / сплетение / микс техник
- Аксессуары: заколки, венок, Schleier, свежие цветы, жемчуг, ленточки — закрепление невидимыми шпильками
- Финальная фиксация: профильный лак (сильная/экстра-сильная) + термозащита от влаги
- Мини-набор для тач-апа (лак, невидимки, гумка) — в подарок

### Результат
Причёска держит 12–18+ часов: не теряет объём, не расплетается, не мокнет от влаги/слез/пота. Выглядит на фото/видео как «сделано только что». Время — 1–2 ч. Свадебный пакет: пробник + день свадьбы + тач-ап набор.
